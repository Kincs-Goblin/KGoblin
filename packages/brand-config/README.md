# packages/brand-config

Állapot: csak terv.

Brandenként egy típusos, Zod-dal validált config: `id`, `domains`, Woo-végpont (env-kulcs neve), `locale`,
`currency`, `theme` (design tokenek), `texts`, `payments`, `analytics`, `search`. Titok nem kerül ide, csak
az env-változó neve.

Mezők és új brand checklistje: `.agents/skills/kg-architecture/references/multi-brand.md`.
