# src/pages - oldalak

Egy szelet = egy útvonal kompozíciója (`<slice>/ui/<Name>Page.tsx` + `index.ts`), logika nélkül. A Next
`app/` mappája innen re-exportál.

Tervezett szeletek: `home`, `catalog`, `product`, `search`, `cart`, `checkout`, `order-confirmation`,
`account`, `auth`, `legal`, `not-found`.
